# Siddhesh Barabde | Personal Portfolio Website

A responsive portfolio with a sidebar layout, a live Excel-style dashboard and interactive demos of my documented projects.

**Live website:** https://YOUR-PROJECT.vercel.app *(add after deploying)*
**Repository:** https://github.com/Siddhesh12062007/portfolio *(use your repo name)*

## Features
- Sections: Home, About, Skills, Projects, Excel Dashboard, Live Demos, Education, Achievements, Experience, Contact
- NASA Space Apps Challenge 2025 (Team Leader) featured under Achievements
- Live Movie & OTT dashboard (650 titles) with Type, Platform and Language filters, rebuilt from my Excel workbook
- Smart Parking simulator and Simulated Annealing scheduler running in the browser
- Downloadable project reports and the Excel workbook
- Dark and light themes, project filtering, animated skill bars, starfield hero
- Responsive on mobile, tablet and desktop; keyboard focus styles; reduced-motion support

## Technologies
HTML5, CSS3, vanilla JavaScript, Google Fonts, Git, GitHub, Vercel

## Run locally
```bash
git clone https://github.com/Siddhesh12062007/portfolio.git
cd portfolio
npx serve .
```
Or open `index.html` directly in a browser.

## Project structure
```
portfolio/

├── js/main.js            # theme, dashboard, demos
├── js/ott-data.js        # cleaned OTT dataset (650 rows)

```

## Deploy to Vercel
1. Push to GitHub. 2. Vercel → Add New → Project → import the repo. 3. Framework "Other", no build command → Deploy. Every push to `main` redeploys.
